# 收入规划模拟器 📊

家庭财务全景推演工具，基于个人/家庭的完整财务状况，分析从当前到退休期间每月需多少收入，才能保证退休时家庭存款达到目标水平。

## 如何使用

1. **直接打开** `index.html` 文件（浏览器会自动加载）
2. 填写左侧面板的各项参数
3. 点击 **「开始计算」** 查看结果
4. 在 **「计算模式」** 中切换：
   - 🎯 **目标求解**：输入退休目标存款，反推每月所需收入
   - 📈 **方案推演**：输入当前月收入，预测退休时存款

## 功能特性

- ✅ **9大财务维度**：基本信息、经济假设、资产、负债、月度支出、子女（可多个）、人情往来、收入、退休目标
- ✅ **目标反推**：二分查找算法精确求解所需月收入
- ✅ **逐年模拟**：通胀调整、薪资增长、复利投资，逐年计算至预期寿命
- ✅ **4种图表**：存款增长曲线、收支对比、支出构成（可切换年份）、敏感性分析
- ✅ **年度明细表**：逐年查看收入、支出、现金流、存款变化
- ✅ **名义值/实际值切换**：查看未来名义金额或折合至今的实际购买力
- ✅ **导出 CSV**：将明细数据导出为 Excel 可打开的 CSV 文件
- ✅ **保存配置**：参数保存到浏览器本地存储，下次打开自动恢复
- ✅ **动态子女/负债**：可添加多个子女和多笔贷款

## 输入维度说明

| 维度 | 说明 |
|------|------|
| 基本信息 | 当前年龄、配偶年龄、退休年龄、预期寿命 |
| 经济假设 | 通胀率、投资回报率（退休前后）、薪资增长率、税率 |
| 当前资产 | 现金存款、股票/基金、房产净值、其他资产 |
| 负债 | 房贷、车贷等（逐笔添加，含月供和剩余年限） |
| 月度支出 | 生活、水电、通信、交通、租金、保险、医疗、娱乐等 |
| 子女信息 | 多子女分别配置年龄、月花费、教育费、大学基金目标 |
| 人情往来 | 月均人情开支 + 年度大额红包/婚礼 |
| 收入 | 当前月薪、其他收入、退休后养老金 |
| 退休目标 | 目标存款额 |

## 技术说明

- 纯前端应用，无需安装任何软件
- 使用 Chart.js 渲染图表
- 所有数据在浏览器本地计算，不会上传到服务器
- 建议使用 Chrome / Edge / Firefox 最新版打开

⚠️ 本工具为财务模拟估算，不构成投资建议。实际结果可能因市场波动、政策变化、个人情况差异等因素与模拟结果存在重大差异。
